# Local image utilities
Research-stage Python utilities, not browser production code. Install requirements-dev.txt and run unittest discovery. JPEG/PNG/WebP decoding with 15,000,000 byte input cap and 24 MP provisional pixel cap. Animation and unsupported color modes rejected. Embedded ICC profiles rejected pending color-managed export. PNG re-encoding omits copied metadata and preserves oriented decoded pixels. Output may exceed input cap; no production memory/time guarantees. RGB-only MSE and PSNR are image fidelity measures, not protection scores. No network operations, face processing or adversarial perturbations. Generated geometric or solid-color test fixtures only.
